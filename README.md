# Сайт парикмахерской: дизайн и вход в личный кабинет

Статический проект без сборки, один файл `index.html`. Готов к загрузке на Vercel.

## Что внутри
- `index.html`: главная страница (дизайн, услуги, мастера с анимацией карточек) и личный кабинет владельца и администратора. Вход открывается кнопкой «Вход» в шапке сайта, отдельной страницы кабинета нет.
- `privacy.html` и `consent.html`: политика конфиденциальности и согласие на обработку персональных данных (адреса `/privacy` и `/consent`). Все места, выделенные золотистым фоном в квадратных скобках, нужно заполнить реквизитами оператора и проверить у юриста до запуска.
- `fonts/`: шрифт Sansation (Light, Light Italic, Regular, Bold) и лицензия `OFL.txt`. Файлы шрифта не изменялись, лицензию из папки удалять нельзя.
- `vercel.json`: заголовки безопасности и кэширование шрифтов
- `robots.txt`

## Деплой на Vercel
**Через GitHub (рекомендуется)**
1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. На vercel.com: Add New, Project, выберите репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми. Нажмите Deploy.

**Через консоль**
```
npm i -g vercel
cd salon-site
vercel --prod
```

## Важно
- Это прототип интерфейса. Вход демонстрационный: кнопки «Войти как владелец» и «Войти как администратор» доступны любому посетителю сайта. Услуги и мастера, добавленные в кабинете, сразу появляются на сайте и сохраняются в браузере (localStorage): их видно только на этом устройстве. Остальные данные кабинета (записи, отзывы) хранятся только в памяти страницы.
- Для боевого сайта вход нужно заменить на вход через Telegram с проверкой на сервере. Пока этого нет, на публичном домене кнопку «Вход» лучше не показывать.
- Все имена, цены, телефоны и описания в проекте заглушки.
