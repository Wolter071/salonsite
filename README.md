# Сайт парикмахерской: дизайн и прототип кабинета

Статический проект без сборки. Готов к загрузке на Vercel.

## Что внутри
- `index.html`: главная страница (дизайн, услуги, мастера с анимацией карточек, призыв к записи)
- `admin/index.html`: прототип личного кабинета владельца и администратора (адрес `/admin`)
- `vercel.json`: заголовки безопасности и запрет индексации `/admin`
- `robots.txt`: запрет индексации `/admin`

## Деплой на Vercel
**Вариант 1. Через GitHub (рекомендуется)**
1. Создайте репозиторий и загрузите в него содержимое этой папки.
2. На vercel.com: Add New, Project, выберите репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставьте пустыми. Нажмите Deploy.

**Вариант 2. Через консоль**
```
npm i -g vercel
cd salon-site
vercel --prod
```

## Важно
- Это прототип интерфейса. Кабинет хранит данные только в памяти страницы, вход демонстрационный, Telegram-бота и базы данных пока нет.
- Не оставляйте `/admin` на боевом домене: любой, кто знает адрес, сможет открыть демо-кабинет. Он не содержит реальных данных, но и защиты у него нет.
- Все имена, цены, телефоны и описания в проекте заглушки.
